Apa fungsi class fixed di baris itu?

Hampir, tapi meleset dikit 🔍

fixed itu bukan "paling depan" — dia itu nempel pake lem super ke layar. Coba scroll halaman ini; elemen dengan fixed bakal diam di tempat, nggak ikut jalan. Buat "paling depan" di-front-lé itu job-nya z-index, beda orang.
